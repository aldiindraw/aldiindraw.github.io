01 · Peminjaman ruangan kampus UGM

SiRuangan

Aplikasi fullstack untuk mengajukan dan menyetujui peminjaman ruangan di lingkungan kampus. Dikerjakan tim empat orang dengan metode Agile/Scrum. Peran saya ada di fitur booking, dashboard persetujuan, dan penyambungan antarmuka dengan API.

  • Endpoint API booking di FastAPI
  • Dashboard persetujuan admin di Next.js
  • Profil pengguna dengan Google OAuth
  • Jendela detail booking dengan mode gelap
  • Perbaikan proxy /api di Next.js
  • Alur kerja pull request di GitHub

02 · Proyek kelompok Sistem Temu Balik Informasi

Mesin pencari catatan medis

Mesin pencari untuk catatan klinis teks bebas yang dipasang sebagai modul di OpenMRS. Membandingkan lima varian pencarian, dari BM25 polos sampai normalisasi istilah klinis (negasi, singkatan, sinonim).

  • Lima varian pencarian dibandingkan
  • 2.316 dokumen MTSamples dan 50 query
  • Normalisasi klinis tidak menurunkan kualitas
  • Waktu respons sekitar 3,6 kali lebih cepat
  • Mode bandingkan semua varian
  • Keterbatasan dicatat di laporan
JavaApache LucenePythonOpenMRS
Lihat di GitHub ↗

Tangkapan layar asli

Hasil evaluasi K=10: BM25 polos P@10 0,540 dan nDCG@10 0,683; normalisasi klinis P@10 0,542 dan nDCG@10 0,687. Selisihnya kecil; penilaian relevansi semi-otomatis.
