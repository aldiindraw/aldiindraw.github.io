# Portofolio Aldi Indrawan (kode sumber)

Situs Next.js 15 (App Router, React 19, TypeScript, Tailwind CSS 4, Lenis) yang diekspor statis.

## Menjalankan
```
cd source
npm install
npm run dev      # pengembangan
npm run build    # hasil ekspor statis ada di folder out/
```
Hasil `out/` disalin ke root repo ini supaya GitHub Pages bisa menyajikannya.

## Mengubah isi
Semua teks ada di `src/lib/data.ts` (profil, keahlian, proyek). Foto ada di `public/images/`.

## Lisensi
Logo teknologi berasal dari paket devicon (lihat `public/logos/LICENSE-devicon.txt`).
